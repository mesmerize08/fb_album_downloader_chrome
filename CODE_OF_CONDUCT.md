# Code of Conduct

This is a small project with a single maintainer. The short version: be decent
to each other.

## Expected

- Assume good faith. Most disagreements here are about a Facebook DOM quirk, not
  about character.
- Keep criticism on the code and the behaviour, not on the person.
- Accept that "no" is a complete answer about scope. The maintainer decides what
  this project is for, and declining a feature is not a slight.
- Respect the privacy of people who are not in this repository. Issues and pull
  requests are public, and this project handles other people's photographs.
  Redact album titles, owner names, photo IDs, and faces before posting.

## Not acceptable

- Harassment, personal attacks, or demeaning comments of any kind, including
  about anyone's identity or level of experience.
- Posting other people's private information, or images of identifiable people,
  without their consent.
- Deliberate derailing, or persistently reopening a settled decision.
- Using the issue tracker to coordinate downloading content someone does not
  have the right to.

## Scope

This applies in issues, pull requests, discussions, commit messages, and any
other space connected with this project.

## Enforcement

Report a problem privately by opening a
[private security advisory](https://github.com/mesmerize08/fb_album_downloader_chrome/security/advisories/new)
— it is the only private channel this repository has, and it reaches the
maintainer directly. For anything involving another account's conduct, GitHub's
own [report abuse](https://github.com/contact/report-abuse) form is the better
route, since GitHub can act where a repository maintainer cannot. Reports are
handled confidentially.

The maintainer may edit or delete content, and block accounts, at their own
discretion. For a single maintainer in their spare time, that is the whole
enforcement mechanism — there is no committee and no appeals process.
